# Provide feedback on the Microsoft Defender for Endpoint client analyzer tool

If you have feedback or suggestions that would help us improve the Microsoft Defender for Endpoint client analyzer, use either of these options to submit feedback:

- In the Microsoft Defender portal at <https://security.microsoft.com>, select **Feedback** at the top of the page, and then fill out the information in the **Submit feedback to Microsoft** flyout that opens:

  :::image type="content" source="media/defender-portal-feedback.png" alt-text="Screenshot of the Feedback icon at the top of the Microsoft Defender portal." lightbox="media/defender-portal-feedback.png":::

  :::image type="content" source="media/defender-portal-submit-feedback.png" alt-text="Screenshot of the Submit feedback to Microsoft flyout in the Microsoft Defender portal." lightbox="media/defender-portal-submit-feedback.png":::

- Select **Send feedback** on the centralized feedback platform for Microsoft Defender XDR and related services at <https://aka.ms/M365Defender/Feedback> and fill out the information in the **Post public feedback** page that opens:

  :::image type="content" source="media/defender-feedback.png" alt-text="Screenshot of the Post public feedback page from the Microsoft Defender XDR feedback page." lightbox="media/defender-feedback.png":::
