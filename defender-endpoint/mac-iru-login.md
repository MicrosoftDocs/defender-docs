# Sign in to Iru to set up Microsoft Defender for Endpoint on macOS

1. Sign in to the Iru console

2. In the Endpoint menu on the left navigation menu, select Library

3. In Library, select Add Library Item in the top-right corner

4. Search for Microsoft Defender, then select Add and configure in the bottom-right

5. On the Microsoft Defender app screen, set the following settings:
  - Installation: Continually enforce
  - Version enformcement: Automatically enforce new updates (recommended)
  - Enforcement timeframe: Set as required
  - Phased rollout: Set as required
  - Pre- or post-install scripts: Set as required

Once complete, hit Save
