# Lateral movement alerts



|<details><summary>Suspected exploitation attempt on Windows Print Spooler service</summary>**Description**:<br>
Adversaries might exploit the Windows Print Spooler service to perform privileged file operations in an improper manner. An attacker who has (or obtains) the ability to execute code on the target, and who successfully exploits the vulnerability, could run arbitrary code with SYSTEM privileges on a target system. If run against a domain controller, the attack would allow a compromised non-administrator account to perform actions against a domain controller as SYSTEM.<br>
This functionally allows any attacker who enters the network to instantly elevate privileges to Domain Administrator, steal all domain credentials, and distribute further malware as a Domain Admin.<br>**Learning period**: None<br> **MITRE**:<br>**Primary MITRE tactic **:  [Lateral Movement (TA0008)](https://attack.mitre.org/tactics/TA0008) <br>- **MITRE attack technique**:  [Exploitation of Remote Services (T1210)](https://attack.mitre.org/techniques/T1210/)<br> - **MITRE attack sub-technique**: N/A**Suggested steps for prevention**:<br>1. Due to the risk of the domain controller being compromised, install the security updates for [CVE-2021-34527](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-34527) on Windows domain controllers, before installing on member servers and workstations.<br>1. You can use the Defender for Identity built-in security assessment that tracks the availability of Print spooler services on domain controllers. [Learn more](/defender-for-identity/security-assessment-print-spooler).</details>||High or Medium|2415|
